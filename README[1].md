# Rayeen International Community (RIC) Website

A responsive one-page starter website for RIC.

## Included
- Professional homepage
- About / Vision / Mission
- Focus areas
- Featured initiatives
- Membership call-to-action
- News & activities
- Contact section
- Responsive mobile layout

## Important before publishing
1. Replace the placeholder email with the official RIC email.
2. Add verified office address/contact details.
3. Add the final constitution and approved organisational details.
4. Connect membership/profile forms to a secure backend or form service.
5. Add Privacy Policy and data-consent language before collecting member information.
6. Replace placeholder initiative links with the actual portals/forms.

Open `index.html` in a browser to preview the website.
